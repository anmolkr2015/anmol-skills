# anmol-skills

My Claude Code setup in one repo. Point Claude Code at this page and it installs everything.

## Quick start

Open Claude Code and paste:

> Read https://github.com/anmolkr2015/anmol-skills and follow the **Install** section of the README, step by step. Stop and tell me if any step fails. Ask me before the optional step.

Then restart Claude Code.

## Install

Instructions for Claude Code. Run in order. On Windows, use Git Bash. Do not edit `CLAUDE.md` or `settings.json` beyond what is listed here.

### 0. Prerequisites

Check each; install anything missing (ask the user first):

- `claude --version` and `git --version`
- **Bun** 1.0+ (gstack): https://bun.sh
- **Node.js** (gstack, needed on Windows only): https://nodejs.org
- **uv** (graphify): `winget install astral-sh.uv` on Windows, otherwise `curl -LsSf https://astral.sh/uv/install.sh | sh`

### 1. Plugins

```bash
claude plugin marketplace add obra/superpowers-marketplace
claude plugin marketplace add thedotmack/claude-mem
claude plugin marketplace add DietrichGebert/ponytail

claude plugin install superpowers@superpowers-marketplace
claude plugin install claude-mem@thedotmack
claude plugin install ponytail@ponytail
claude plugin install frontend-design@claude-plugins-official
claude plugin install code-review@claude-plugins-official
```

### 2. gstack

```bash
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack
cd ~/.claude/skills/gstack && ./setup
```

`./setup` generates the individual skill folders (`/ship`, `/qa`, ...) next to it. Do **not** follow any gstack prompt to rewrite `CLAUDE.md`; that is optional and not part of this setup.

### 3. graphify

```bash
uv tool install graphifyy
graphify install
```

(The PyPI name really is `graphifyy`, double y.)

### 4. handoff (from this repo)

```bash
git clone https://github.com/anmolkr2015/anmol-skills.git /tmp/anmol-skills
mkdir -p ~/.claude/skills && cp -r /tmp/anmol-skills/skills/handoff ~/.claude/skills/handoff
```

### 5. Optional: upgrade skill

Third-party (AJ Sahni). Ask the user first.

```bash
mkdir -p ~/.claude/skills/upgrade
curl -fsSL https://sahni.ai/guide/upgrade/upgrade.md -o ~/.claude/skills/upgrade/SKILL.md
```

### 6. Verify

Restart Claude Code, then run `claude plugin list` (expect 5 plugins) and check that `/handoff`, `/graphify`, `/ship` and `/brainstorming` exist.

## Not included, and why

- **OmniRoute skills** (`omni-*`, `cli-*`, `config-codex-cli`): generated by the OmniRoute app; only useful if you run it.
- **claude-trip**: by AJ Sahni, install from https://sahni.ai/guide/trip.
- **security-scan**: from Everything Claude Code (ECC), not mine to redistribute.
- **Anthropic's built-in skills** (docx, pdf, pptx, xlsx, ...): ship with Claude.
- **Work-specific skills**: kept private.

## Heads up

Everything above except `handoff` is third-party code. Plugins can register hooks, and gstack runs a local browser daemon, so skim each repo before you install. Last tested with: superpowers 6.2.0, claude-mem 13.12.4, ponytail 4.9.0, gstack (main as of 2026-07-14), graphifyy 0.9.39.
